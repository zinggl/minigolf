# Raphaels Minigolf

Ein Minigolf-Spiel von Raphael. Spielen: https://zinggl.github.io/minigolf

So geht's: Finger auf das Spielfeld, vom Ball weg ziehen, loslassen = Schlag.

- `holes.js` – die Bahnen (Start, Loch, Hindernisse, Par)
- `game.js` – Spiellogik und Zeichnen
- `index.html`, `style.css` – die Seite
